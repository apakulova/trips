# Trips

Статические путеводители и материалы о поездках.

Главная страница: <https://apakulova.github.io/trips/>

Сейчас опубликованы путеводители по Белграду, Алтаю и Рязани, а также памятка по поездке в Турцию.

Карточки на главной берутся из `guides.json` и автоматически сортируются от новой поездки к старой по `startDate` в формате `ГГГГ-ММ-ДД`. Для обложки указывайте отдельное чистое фото в `cover`, без подписи на изображении.

Путеводитель по Белграду: <https://apakulova.github.io/trips/belgrade-2026/>

Путеводитель по Алтаю: <https://apakulova.github.io/trips/altai-2026/>

Памятка по Турции: <https://apakulova.github.io/trips/turkey_2026_mom_guide/>

Путеводитель по Рязани: <https://apakulova.github.io/trips/ryazan_2026/>
